# 바다정보·위판 동향

공개 `/sea`, `/market?view=trends`, GET `/api/v1/sea/ports`, `/api/v1/sea/conditions?port=sinjin`, `/api/v1/market/trends?period=week`를 제공한다. 기존 `/market` 가격 조회와 중매인 권한은 유지한다. 조회 요청은 DB만 읽는다.

## 승인 대기 배포와 활성화

현재 실제 신규 API 활용승인은 대기 중이다. 화면과 작업 프로세스는 먼저 배포하고 데이터는 꾸며 넣지 않는다. API 계약을 fixture로 검증한 것은 실제 연동 검증이 아니다.

서버 `.env`에 아래 설정을 적용한 후 `pm2 restart mansun-market-data`와 `pm2 restart mansun-market-web`으로 반영한다. 키를 저장소·브라우저·로그에 남기지 않는다. `/admin`에서 개별 작업의 재시도를 예약하면 정기 간격을 기다리지 않고 수집한다. 별도 API 승인은 서비스마다 필요하다. 중량 단위 설정이 바뀌거나 위판장 위치 매핑이 변경되면 최근 30일을 자동 재예약해 최초 백필에도 반영한다.

| 환경변수 | 신청·설정 |
| --- | --- |
| `AUCTION_SERVICE_KEY` | [해양수산부 일자별 위판](https://www.data.go.kr/data/15057689/openapi.do) |
| `MOF_SERVICE_KEY` | 기존 [위판장 위치](https://www.data.go.kr/data/15056511/openapi.do) 신청·키 재사용. 지역은 주소로 매핑하며 미매칭은 지역 미확인 |
| `KHOA_SERVICE_KEY` | [국립해양조사원 고조·저조](https://www.data.go.kr/data/15156018/openapi.do) |
| `KMA_SERVICE_KEY` | [해상예보](https://www.data.go.kr/data/15058629/openapi.do), [단기예보](https://www.data.go.kr/data/15084084/openapi.do), [특보현황](https://www.data.go.kr/data/15000415/openapi.do), [예보구역](https://www.data.go.kr/data/15057111/openapi.do) 모두 신청 |
| `KHOA_STATIONS` | 공식 조석 관측소 목록으로 확인한 JSON. 키는 sinjin/incheon/gunsan/mokpo/yeosu/tongyeong/busan/pohang/sokcho/jeju, 값은 관측소 코드. sinjin은 안흥 지점. 응답의 관측소 이름이 일치하지 않으면 게시하지 않음 |
| `AUCTION_WEIGHT_UNIT` | 일자별 API의 `csmtWt` 단위가 kg임을 계약/실응답으로 확인한 후 `kg`. 확인 전에는 금액만 보관하고 kg 값과 kg당 가격은 비워 둠 |

최초 활성화 검증: 날짜·관측소·예보구역 및 발표 회차를 공식 화면과 대조하고 위판 단위·구매번호/순번의 고유성을 확인한다. 일부 제공처의 단위·지점 목록은 공개 웹 설명만으로 확정할 수 없어 설정을 요구한다. 이 설정 없이 실제 자료 연결이 완료되었다고 보고하지 않는다.

## 수집·복구

`pnpm db:migrate`는 추가형 `scripts/marine-schema.sql`을 실행한다. 운영에서는 해당 SQL만 트랜잭션으로 먼저 적용해도 된다. 별도 PM2 `mansun-market-data`가 `scripts/marine-worker.ts`를 실행한다. 기존 알림/가격 수집 프로세스와 독립한다.

- 한국 시각: 물때 00:20(향후 7일), 위판 06:30/12:30/18:30(최근 7일 정정), 기상 1시간, 특보 5분, 지점 메타데이터 7일 간격. 최초 실행에는 즉시 작업을 만든다.
- 최초 최근 30일을 최근 날짜부터 채운다. 성공한 7일 이전 자료는 자동 재수집하지 않는다. 관리자 재예약은 가능하다.
- 위판과 기상은 별도 실행 경로로 처리한다. 한 번에 100행/페이지, HTTP 20초, DB lease 60초, 페이지 사이 최소 250ms, 설정 키 계열별 하루 8,000회 상한. 오류는 1분부터 최대 1시간 지수 재시도한다. 키/승인 대기는 1시간, 할당량 소진은 다음 날 00:05 재시도한다.
- 페이지별 DB 체크포인트를 저장하며 프로세스 종료 후 lease가 만료되면 이어서 진행한다. 오래된 작업자가 새 작업의 데이터를 반영하지 못하게 토큰을 확인한다. 연결 실패·5xx·JSON 파싱 실패·인증 대기·할당량 초과는 받은 페이지를 유지한 채 재시도한다. 전체 건수 변경·행 검증 실패는 임시 페이지를 버리고 새 회차로 재수집한다. 수집 중인 작업은 신규 백필 날짜보다 우선한다.
- 최대 500,000행/회차. 모든 페이지·식별자·수치를 검증한 뒤 트랜잭션으로 게시한다. 실패·빈 응답은 기존 정상 자료를 유지한다. 정상 0건 응답은 별도 empty 상태로 다음 정기 시각에 재확인하며 오류 알림을 보내지 않는다. 30일보다 오래된 미완료 날짜는 자동 재시도를 중지하고 관리자 재예약으로 확인한다. 빈 날을 무거래 0으로 단정하지 않는다.
- `/admin`에 작업 진행, 성공 시각, 메시지, 다음 실행, 작업자 heartbeat를 표시한다. 반복 오류는 관리자 앱 내 알림으로 제공처·날짜·회원당 한 번 알린다.

## 표시 원칙

신진도 인근을 기본으로 전국 주요 항구 10개를 제공한다. 마지막 선택은 해당 브라우저에 저장한다. 고조/저조는 관측소 예측값이며 연속 조위 곡선이나 조류 세기로 추정하지 않는다. 해상예보는 공식 구역명을 표시하고, 항구 좌표를 변환한 5km 육상 격자의 기온·강수와 구분한다. 특보는 최신 전국 원문 하나만 표시하며 지역별 무특보를 추론하지 않는다. 수집 실패·15분 이상 갱신 지연은 현재 특보로 단정하지 않는다.

위판 통계 기본일은 오늘 이전 최신 수집 완료일이다. 일간은 전날, 주간은 종료일을 포함한 7일과 바로 앞 7일이다. 한 날짜라도 미수집이면 해당 기간 합계·증감을 비운다. 기간이 모두 수집됐을 때만 해당 조건의 무거래를 0으로 취급한다. 전기 0이면 절대 증감만 제공하고 %는 계산하지 않는다. 전체 어종의 평균 가격을 표시하지 않는다. 같은 어종·상태·규격·단위의 합계금액/합계중량만 제공하며 무효 중량/금액이 섞이면 가격을 보류한다. 어종 표는 최대 200조건이며 더 많으면 필터 안내를 표시한다.

롤백은 이전 코드/빌드로 되돌리고 data 프로세스만 중지한다. 추가 테이블과 운영 환경·업로드를 삭제하지 않는다.

공식 통계의 공개 조회 결과는 웹 프로세스에서 최대 100조건·30초 캐시한다. 지역 미확인 행이 남은 날짜는 지역별 조회의 완료 날짜로 취급하지 않는다.

공식 계약 근거: 15156018 상세 Swagger의 `predcTdlvVl`는 cm, `extrSe`는 1 오전 고조/2 오전 저조/3 오후 고조/4 오후 저조다. [기상청 발효번호 설명](https://apihub.kma.go.kr/static/html/attach/fct_shrt_table.html)과 [해상예보 구역·필드](https://apihub.kma.go.kr/apiList.do?seqApi=10)를 참조한다. 15058629의 해상예보 상세기능은 12A20100=서해중부앞바다, 12B20100=남해동부앞바다를 명시한다.
