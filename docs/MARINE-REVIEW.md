# 바다정보·위판 동향 리뷰 기록

범위: 바다정보 페이지, 공식 일별 위판 통계, 별도 수집 작업자, 추가형 DB 스키마, 공개 API와 관리자 재시도, 메뉴. 기존 미커밋 브랜딩·아이콘은 범위에서 제외했다.

## 1회차

독립 Codex 및 `scripts/review.sh claude`를 동시에 실행했다. 둘 다 CHANGES_REQUESTED.

- 완료 기간에 어종 거래가 없을 때 NULL로 표시: 코드로 확인, 거래 없음만 0으로 보정. 새로 등장하거나 사라진 어종을 정상 비교한다.
- 일부 날짜만 있는 주간의 어종 합계 노출: 코드로 확인, 전체 기간 미완료 시 물량·금액을 비운다.
- 0중량 거래 금액이 kg당 가격에 섞임: 코드로 확인, 불확실한 행이 섞인 조건의 kg당 가격을 보류한다.
- 정상 0건의 영구 오류·알림: empty 상태로 분리하고 정기 재시도, 30일 이전 미완료 자동 재시도를 중지한다. 기존 자료는 보존하고 0건을 무거래로 단정하지 않는다.
- 일시 오류의 페이지 체크포인트 초기화: 연결·5xx·JSON·할당량 오류는 페이지 유지. 검증 실패만 새 회차. 수집 중인 날짜 우선.
- 그 외 반영: 설정/위판장 메타데이터 변경 시 최근 30일 재예약, 해상예보 발표 TTL 14시간, MOF 인증 오류 대기 분류, 공개 응답에서 환경변수 이름 제거, 잘못된 페이지 날짜 보정, 빈 위판장 주소 허용, 항구 목록 prop 전달, 공개 통계 30초 캐시, 회귀 테스트 추가.
- 기각: 조석 구분·단위 근거 미확인. 공공데이터포털 15156018 상세 Swagger가 `extrSe` 1/3 고조·2/4 저조 및 `predcTdlvVl` cm를 명시한다. 자료 화면은 실제 API 승인·관측소 매핑 확인 전까지 대기한다.
- 기각: 해상 광역 예보구역 사용 가능 여부 미확인. 15058629 해상예보 상세기능에서 12A20100 서해중부앞바다·12B20100 남해동부앞바다를 예제로 명시한다. 실제 코드는 공식 구역 메타데이터의 이름 일치로 결정하며 응답 구역코드도 대조한다.

## 검증

타입 검사·린트·단위/DB 테스트 69개, 로컬 및 운영 준비 디렉터리 빌드, 기존 게시판 모바일 E2E 1개를 통과했다. agent-browser로 320px·1280px 레이아웃, 항구 저장·선택 동기화, 7일 날짜, 통계 전환·잘못된 날짜 복구, 공개 API, 비로그인 재시도 401을 확인했다.

실제 신규 공공 API는 활용승인 대기 상태이다. fixture 검증은 실제 연동 성공을 뜻하지 않는다. 최초 키·관측소·중량 단위 확인 후 공식 원문 대조가 남는다. 사용자는 이 상태를 화면에 명시한 선배포를 승인했다.

## 2회차

새 컨텍스트의 독립 Codex와 `scripts/review.sh claude`를 동시에 실행했으며 둘 다 `VERDICT: APPROVE`를 받았다. major·blocker 없음.

이후 minor만 보완했다. 오래된 날짜에 예약한 관리자 재시도를 sweep이 취소하지 않게 했고, 승인·빈 응답·할당량 대기는 오류 횟수에 누적하지 않으며 페이지 진척 시 연속 오류 횟수를 초기화한다. 제공처 코드 22/03과 XML 인증 오류를 분류하고 인증 대기 때도 체크포인트를 보존한다. 실제 지역 매핑 변경 때만 재수집하며 동일 코드 중복 구역은 하나로 비교한다. 빈 자료·중량 확인 대기 문구와 모바일 메뉴 접근성 이름을 보완했다. 회귀 테스트 3개를 추가했다.

기각/보류한 minor:
- 강제 0건 확정 게시 제안: 제공처의 0건이 최종 무거래임을 아직 확인하지 못했으므로 미수집을 0으로 바꾸지 않는 승인된 보수적 정책을 유지한다. 실제 활용승인 뒤 계약과 원문 대조가 필요하다.
- 17시 `numEf=0`의 밤 라벨(미확인 기억): 확인한 기상청 공식 DB 설명은 0을 오늘 오전/오후로 명시한다. 지금은 공식 반일 구분을 따르며 신규 실응답 검증에서 최신 통보문을 대조한다.
- 전국 예보구역을 고정 코드로 대체: 확인되지 않은 코드를 추정하지 않는다. 이름에 다른 코드가 여러 개면 연결 대기로 남기는 쪽을 유지한다. 실제 승인 이후 구역 목록 유효기간을 함께 확인한다.

AGENTS.md의 양쪽 승인 후 minor 수정 규정에 따라 추가 리뷰 없이 타입·린트·전체 테스트·빌드를 다시 검사한다.
