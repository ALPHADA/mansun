# 풍어 제품 결정

45개 기획 질문과 후속 수정으로 합의한 첫 버전입니다.

## 이용자와 가치

전국 중매인의 물건을 발견하고 새 거래처와 연락하도록 돕습니다. 구매자 명칭은 매입회원입니다. 차량판매·수산물 소매·도매·냉동유통·가공업체가 대상입니다. 냉동·냉장 보관업체는 별도 주 역할로 가입합니다. 계정 하나에 주 역할 하나, 변경은 운영자가 처리합니다.

신진도 중매인 1명과 기존 거래처가 초기 현장 검증에 참여하지만 지역별 가입 제한은 없습니다. 선어·활어, 품목별 단위, 현장 픽업이 초기 주 거래 흐름입니다. 중매인 소개에 취급 어종과 경매 매입 대행 여부를 표시하고, 상품으로는 이미 확보한 물건만 올립니다.

## 회원과 공개 범위

카카오 로그인을 기본으로 제공하고 처음 가입할 때 업종을 받습니다. 문자 OTP 로그인은 발송 서비스 설정 시 추가로 제공합니다. 중매인도 사전 승인 없이 가입 즉시 물건을 올릴 수 있고(2026-10-04 변경), 운영자는 문제가 있는 계정을 이용 정지합니다. 비로그인 상품 열람은 가능하지만 가격·연락처·상세 픽업 위치는 회원만 확인합니다. 매입 요청 게시판은 회원에게 공개합니다. 카카오 가입자의 업무 연락처는 직접 입력하며 인증된 번호라고 표시하지 않습니다. SMS 가입자는 인증된 번호를 사용합니다.

## 등록과 일별 정보

사진, 어종, 상태, 규격, 지역, 위판장·판매 장소, 단위, 가격 범위, 대략적인 물량, 최소 구매량, 픽업 조건이 필요합니다. 자정에 마감하며 다음 날에는 복사 후 재확인합니다. 서로 다른 단위·규격·상태·상자 중량을 섞어 집계하지 않습니다. 물량은 등록 당시 수량이며 전체 위판량이나 잔량이 아닙니다.

회원 제시 판매가와 공식 경락 자료는 완전히 구분합니다. 검증된 공식 자료가 없어도 핵심 거래 연결은 사용할 수 있습니다. 시연 가격은 실제 집계에서 제외합니다.

## 알림과 운영

첫 버전은 웹 내부 알림만 제공합니다. 관심 지역·어종에 맞는 새 물건·매입 요청을 하루 한 번 요약합니다. 기본 오전 7시, 회원 변경 가능, 일별 중복 방지입니다. 카카오 연결은 후속 단계입니다.

여러 운영자가 신고, 게시물 숨김, 회원 이용 제한과 역할 변경을 수행하며 처리 기록을 남깁니다. 실제 거래는 전화·문자로 협의하고 외부에서 결제합니다. 연락 버튼 클릭은 거래 성사 지표가 아닙니다.

## 성공 기준과 후속 단계

2주 관찰을 기본으로 일별 등록자와 재방문을 확인합니다. 초기 무료 운영 후 수익 모델을 결정합니다. 큰 글씨·사진·명확한 버튼 중심의 반응형 웹을 먼저 만들며 네이티브 앱은 후속 단계입니다. 향후 선주·수협 직원의 역할은 별도 기획합니다.
