# 코드 리뷰 지침 (codex·claude 리뷰어 공통)

이 저장소의 **커밋되지 않은 변경**을 리뷰합니다. 파일을 고치지 말고 읽기만 하세요.

1. `git status --short`와 `git diff HEAD`로 변경을 확인합니다. 추적되지 않는 새 파일은 직접 읽습니다.
2. 변경된 코드가 호출하거나 호출되는 주변 코드를 읽어 실제 동작을 확인합니다. Next.js 관련 판단은 `node_modules/next/dist/docs/`의 해당 문서를 근거로 합니다(`AGENTS.md` 참고).
3. 다음 순서로 봅니다: 정확성 버그, 보안·권한·개인정보 노출(비로그인 응답에 가격·연락처·상세 위치가 새는지 포함), 데이터 손실·마이그레이션 위험, 누락된 테스트, 기존 코드 중복. 취향 차원의 지적은 하지 않습니다.

출력 형식:

- 지적마다 한 항목: `[blocker|major|minor] 파일:줄 — 문제`, 이어서 재현되는 구체적 입력·상태와 잘못된 결과, 제안하는 수정.
- 확인하지 못한 추측은 `(미확인)`이라고 표시합니다.
- 마지막 줄은 반드시 `VERDICT: APPROVE` 또는 `VERDICT: CHANGES_REQUESTED` 중 하나입니다. blocker나 major가 하나라도 있으면 `CHANGES_REQUESTED`입니다.
